# 盐瞳 · 盐田航拍波美度分析系统

海盐场技术员每天要跑几十块蒸发池、拿波美计逐池舀样。本系统用无人机清晨一次飞行的数百张照片，
在浏览器里完成 **拼接大图 → 土埂对齐 → 光照拉匀（含早晚校正）→ 池块分割 → 剔除反光/盐花/泥 →
平均水色 → 标定反演波美度 → 浓度图 + 异常预警**，并提供完整的标定管理。

- 纯 **TypeScript + Canvas + Web Worker**，零重型运行时依赖（无 React/OpenCV 也能跑完整管线）。
- 内置**带浓度真值的合成航拍数据集**：按天气、藻类颜色、太阳角度参数化生成，含白色盐花、
  露出泥斑、水面反光、埂上杂物、GPS 抖动，并注入“突然变淡”的渗漏/雨水异常。
- 四个页面：**航拍导入 · 拼接大图 · 池子浓度图 · 标定管理**。

## 精度与性能（本仓库实测）

合成盐田为 **6 行 × 10 列 = 60 块池**，波美度约 2–29 °Bé，最右两列为结晶池。
“当天舀样实测”= 真值 + σ≈0.3 的波美计读数噪声。推荐流程用当天部分/全部舀样与同链路校正后水色
建立盐场自己的标定（`buildSurveyCalibration`），因此标定与反演处于同一光照帧。

**端到端（Vitest，Node）**

- 晴天 + 嗜盐藻华：`60/60` 对当天实测 `|误差| ≤ 1.5 °Bé`，最大约 `0.2–0.9`（随种子/标定密度）。
- 多云/中藻、阴天/寡藻/傍晚暖光等组合同样 `60/60 ≤ 1.5`。
- 边界贴合土埂内沿：平均约 **2.3–3.3 大图 px**、最大约 5–7 px（大图 2800×1800）。
- 注入的 2 个“突然变淡”异常池在各天气/种子下均被检出，且无误报。
- **早晚一致性**：用早晨数据建一个模型，傍晚拼接图**不重新标定直接套用**，仍 `60/60 ≤ 1.5`、
  最大误差约 `0.5`，早晚同池波美度最大差异约 `0.5 °Bé`。

**500 张性能（真实 Chrome，无头，M 系列同级桌面 CPU）**

```
generate 500 photos : ~5.4 s（导入页，Worker，不计入“出图一分钟”）
stitch wall         : ~3.9 s
analysis wall       : ~2.3 s
拼接+分析            : ~6.2 s   ✅ 远低于 60 s
对当天实测           : 60/60，最大绝对误差 ~0.20 °Bé
```

Node/Vitest 中 500 张拼接+分析约 8.5 s（`tests/perf500.test.ts` 断言 `< 60_000 ms`）。

> 上述数字来自开发机实测，会随 CPU 浮动，但距离 60 s 预算有数倍余量。

## 粉红藻色 与 发白结晶 为什么不会互相干扰

- 分类在 HSV/Lab 上用**互斥门限**：白盐花/结晶 = 高亮度 + 低彩度；水面强反光 = 近削顶、极低饱和；
  嗜盐藻粉红 = 高彩度且色相落在红–品红区间。粉红像素彩度高，永远不会进入“低彩度白”门限。
- 二者来自**互斥像素集**：`pinkIndex` 由剔除干扰后的水色 Lab 计算；`whiteIndex` 主要由被剔除的
  盐花覆盖度决定。结晶池因此可以同时 `pinkIndex≈1`（水是粉红/红）且 `whiteIndex` 高（盐花多），
  但白色盐花不进入平均水色。
- 拼接的多照片加权平均本身也会抑制视角相关的太阳耀斑；残留耀斑再由分类器遮掉。

## 合成数据说明（`src/core/synth.ts`）

1. 在 2800×1800 世界坐标渲染规范光照盐田：压实土基底、24 px 笔直网格土埂与中线/亮边、
   埂上枯枝杂物；池水按 `波美度→Lab 标准曲线 + 藻类粉红偏移` 上色，叠加大尺度深浅与波纹、
   藻华斑块；高浓度池生成暖白盐花团与边缘盐壳；部分中低浓度池角生成露出泥斑。
2. 蛇形航线按片数自适应航高/足迹与重叠；每张照片从世界图双线性采样，叠加 GPS 位姿抖动、
   小转角、逐片曝光/色温抖动、天气（晴/多云/阴的反差、饱和、冷暖）、太阳角度方向光梯度/暗角、
   传感器噪声，以及视角相关的反光耀斑。
3. 真值：每池 `trueBaume`、`measuredBaume`、内沿四边形；异常池把浓度人为压低 7–11 °Bé。

```

  core/            # 纯 TS，不碰 DOM，可在 Node/Vitest 与 Worker 中共用

    rng.ts
    brine.ts       # 波美度->水色标准曲线、藻色、粉/白指数、曲线投影

    field.ts       # 6x10 网格、浓度真值/实测/异常
    synth.ts       # 世界渲染 + 数百张照片合成
    classify.ts    # 水/盐花/泥/反光/埂 像素分类
    segment.ts     # 土埂直线网格检测 + 梯度峰内沿吸附 + 边界评测
    stitch.ts      # 光照增益、位姿精修、两遍羽化融合
    analyze.ts     # 颜色提取、当天舀样标定、反演、异常、标注层、评测
    protocol.ts
  workers/         # synth / stitch / analysis 三个 Web Worker
  state/store.ts   # 全局状态 + 标定 localStorage
  state/jobs.ts    # Worker Promise 封装（Vite ?worker）
  ui/              # 四个页面 + Canvas 缩放查看器 + DOM/控件
tests/             # color / pipeline / missions / perf500
scripts/smoke.mjs, perf-browser.mjs
```

## 已知边界

- 真实照片导入目前按选择顺序给规则航线近似位姿，没有做特征点 SfM；最稳的输入仍是带机载
  GPS/规则航线的下视航拍。合成数据走的是同一套“近似位姿 → 土埂对齐精修”流程。
- 标定关系依赖光照锚定到土埂本色；若测区没有裸露土埂，可改用标定页的实测颜色样本直接拟合。
