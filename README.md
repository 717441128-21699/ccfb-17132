# 盐田无人机卤水浓度估测系统

用无人机每天早晨飞一趟航拍，替代技术员拿波美计逐池舀样。系统把一次飞行的数百张照片
拼成全场大图，分出每块蒸发池，剔除水面盐花、泥斑、镜面反光与土埂像素，按卤水平均颜色
反演每块池子的波美度（°Bé），生成盐田浓度图并标记渗漏/进雨水导致的异常变淡池。

纯 TypeScript 实现，核心算法环境无关（同一份代码在浏览器 Web Worker 与 Node 验证脚本中运行），
大图与浓度图用 Canvas 绘制，拼接与颜色分析在 Web Worker 中后台执行。

## 快速开始

```bash
npm install
npm run dev        # 启动开发服务器（四个页面的 Web 应用）
npm test           # 端到端精度/边界/剔除/异常验证（6 种天气×时段）
npm run test:perf  # 500 张照片性能验证（要求 ≤60s）
npm run build      # 类型检查 + 生产构建
```

## 四个页面

| 页面 | 功能 |
| --- | --- |
| 航拍导入 | 选天气（晴/阴）、时段（早/午/晚，对应太阳角度）、航线网格，生成带真值的合成航拍并启动 Worker 流水线 |
| 拼接大图 | Canvas 展示配准融合后的全场大图，叠加贴合土埂内沿的池子边界/编号，可切换图层 |
| 池子浓度图 | Canvas 浓度热力图 + 每池 Bé/误差/有效像素/盐花/反光/泥斑明细表 + 异常清单 |
| 标定管理 | 录入波美计实测 Bé 与航拍 Lab/sRGB 样本，拟合现场标定模型，localStorage 持久化，可恢复内置默认模型 |

## 合成数据集（带真值）

`src/core/dataset.ts` + `src/core/material-map.ts` 按要求自行合成带波美真值的航拍照片：

- **天气**：晴天（含水面镜面反光）、阴天（漫射光、低对比、低强度）
- **太阳角度**：早晨/中午/傍晚三种色温与高度角，傍晚强暖调
- **藻类颜色**：低浓度海水青绿 → 中浓度黄绿/橄榄 → 高浓度因嗜盐藻呈粉红至红色；
  另有无藻黄褐路径，两条路径按藻类强度插值
- **地物**：白色盐花（结晶池）、池底露出泥斑、土埂及杂物、标准中性灰板（光照校正参考）
- **照片差异**：单张 EV 抖动 ±9%、水面微波噪声、55% 重叠的规则航线网格
- **可注入异常**：随机一池突然变淡，模拟渗漏/进雨水

世界材质图只计算一次（空间网格索引加速多边形定位），每张照片仅采样着色，
这是 500 张照片能在 20 秒级出图的关键。

## 算法流水线

1. **缩略图相位相关配准**（`fft.ts` + `stitch.ts`）：迭代 radix-2 FFT，Hann 窗抑制泄漏；
   以无人机 POS footprint 为强先验，配准只做小幅修正，元数据弹簧 + 残差容差 + 单步限幅，
   防止阴天弱纹理下的周期歧义漂移。
2. **参考灰板颜色校正**（`color-correction.ts`）：在融合前对原始照片、线性 sRGB 域做
   von Kries 通道增益 + 强度归一，把晴/阴、早/晚统一到 D65 参考光照（绕开融合 feathering 对小灰板的污染）。
3. **线性光域大图融合**：近中心优先的高次幂距离权重 feathering，消除接缝又避免大范围多图平均偏色。
4. **池子分析**（`analysis.ts`）：多边形沿土埂内沿收缩采样；Lab 空间分区分类，
   粉红藻色（高 a\* 彩度）与白色结晶（高明度低彩度）走不同判别分支、互不干扰；
   剔除盐花/泥斑/反光/埂后做稳健 Lab 均值，样本不足时安全兜底。
5. **Bé 反演**（`calibration.ts`）：(Bé × 藻况) 规则颜色曲面表，先按色度距离加权定藻况，
   再沿该藻况轨迹用完整 Lab 距离细分插值定浓度。
6. **异常检测**：与历史架次比突然变淡、偏离同区相邻池中位数、有效像素占比过低、反光占比过高。

## 指标达成

`npm test` / `npm run test:perf` 的硬性断言：

- 所有天气×时段场景，每池 Bé 估计与真值误差 **≤1.5°Bé**（实测最大约 1.1°，默认模型 0.5°）
- 白色盐花与池底泥斑不计入池水颜色（结晶池均值 L\* 显著低于盐花白）
- 池子边界与土埂内沿贴合（偏差 0px，内沿收缩采样）
- 粉红藻色与发白结晶分开处理、互不干扰
- **500 张照片端到端约 20 秒出浓度图（要求 ≤60s）**，精度最大 0.4°Bé
- 变淡异常池被正确标记

## 目录结构

```
src/core/        环境无关的核心算法（Worker 与 Node 共用）
  brine.ts         卤水 Bé→Lab 颜色物理模型（含藻色路径）
  color.ts / lut.ts 颜色科学(sRGB/XYZ/Lab) + 查找表提速
  fft.ts           FFT 与相位相关
  geometry.ts      多边形/内沿收缩几何
  material-map.ts  世界材质图（一次性地物分类）
  dataset.ts       带真值航拍照片合成
  stitch.ts        配准/位姿/大图融合
  color-correction.ts 灰板光照校正
  calibration.ts   标定模型与 Bé 反演
  analysis.ts      池子像素分类/稳健均值/异常
  pipeline.ts      端到端编排
src/workers/     Web Worker
src/ui/          四个页面、Canvas 绘制、状态管理
test/            Node 端到端验证与性能验证
```
